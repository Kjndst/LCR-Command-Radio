# LCR Helper 0.0.8 Retirement Version

This source snapshot contains the retired Windows **LCR Helper only**. It intentionally does not include the LCR server, Native radio implementation, Discord bot identities, host deployment files or private runtime configuration.

**End of Life:** This code is preserved for reference, historical UI and provenance. It is not a supported Helper update or an installer for the Native-only LCR product.

The final approved Pair and Main images are included at the repository root and as separate release attachments. They were captured by an isolated Win32/Direct2D presentation test. The Main screen's Paired state is a visual test fixture, not real authentication.

This source tree is an independent Helper Cargo workspace. For Windows UI build reproducibility, the historical code requires a separately obtained, appropriately licensed Jura font. Font files are intentionally not included in this public release. Please review third-party asset licenses before rebuilding or redistributing.

**Source code ZIP/TAR generated by GitHub for this release tag refers to this Helper-only snapshot**, not to the repository's default branch, which retains a separate historical development line. This release tag does not modify default-branch source.
